# Decisoes Arquiteturais

Use este diretorio para registrar decisoes futuras que mudem contratos,
fronteiras de modulo, persistencia, politica multi-tenant ou operacao.

Nao crie ADRs retroativos inventando historico. Para decisoes ja refletidas no
codigo, documente apenas o estado atual nos guias de `docs/`.

## Formato Sugerido

Crie arquivos como `YYYY-MM-DD-titulo-curto.md` com:

- contexto;
- decisao;
- alternativas consideradas;
- consequencias;
- plano de rollback ou migracao quando aplicavel.
